Simply run model_run.py to get all the predictions from the pre-created test sets in the folder TestSets, then run evaluation.py to get the evaluation results. 
To obtain the individual TestSets;
Pronouns + Genders = pronouns_gender_swap.py
Locations (Exonym & Endonyms) + Persons (Regional Names) + Random (Random strings) = entity_swap.py
Typos = typos.ipynb + typos_entity.ipynb
